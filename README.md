# Sadia Expense Tracker

A simple, responsive personal expense tracker. Record, edit, delete, and monitor expenses in **PKR**.

## Features

- Add expenses with title, amount, and category
- Edit and delete existing expenses (delete requires confirmation)
- Live **Total Expenses** card that updates after every change
- Form validation and a friendly empty state
- Data is saved in the browser (`localStorage`)

## How to run

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

Then visit the URL printed in the terminal (usually `http://localhost:3000`).

Food, Transport, Shopping, Bills, Entertainment, Other
